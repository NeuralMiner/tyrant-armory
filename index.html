Weight each stat, then optimize

Weights are relative, not percentages — 2:1 and 200:100 pick the same loadout. Each stat is scaled to its own range first, so a weight means the same "how much I care" whether the stat is a flat number or a small percentage.

Pick a preset to auto-fill the weights below — the troop presets build for PvP, single-type or a two-troop march, Gathering builds for resource runs — then tweak as needed. Editing any weight switches this back to Custom.

Set bonuses that only apply in a scenario (e.g. Beastlord's Hunt in Monster Dens) count toward the pick only when that scenario is selected.

Scores every piece at its level cap instead of the level it's on: Attack, Defence and Health projected to max, affixes left exactly as they are — those are rolled from the item's quality when it drops and don't grow with enhancement. Answers "what should I build toward" rather than "what's best right now", so an under-levelled Legendary stops losing to a maxed Rare it will overtake. Totals and item stats read on the same basis while this is on; the Upgrade plan keeps showing today's numbers, since costing those levels is its whole job.
